# Release_A1 Проект — Справка

## Описание
**БУХЛОЧАТ** — официальный хаб для встреч, событий и общих выездов. Это клиентское JS-приложение с простой авторизацией и админ-кабинетом.

## Стек
- Язык: JavaScript, HTML, CSS
- Архитектура: vanilla JS, static site, localStorage-based state
- Дополнительно: fetch для data/events.json, опциональный API proxy через `window.BUHLO_API_URL`

## Структура
```
Release_A1/
├── index.html              # главная страница
├── admin.html              # корневой файл; по факту реальная админка в pages/admin.html
```

## Основные сценарии

### Главная страница (`index.html`)
- блок `auth-overlay` с вопросом и входом
- меню разделов: События, До Нёмана, Встречи, Алкометр, Контакты, ДР
- запуск `js/main.js` на load

### Логика главной (`js/main.js`)
- `DEFAULT_ADMIN_PASSWORD = 'Terminator1981'`
- `EVENTS_KEY = 'buhlo_events_data'`
- `REGISTRATIONS_KEY = 'buhlo_registrations'`
- `checkAuth()` — проверка доступа к хабу
- `initPage()` — инициализация таймера, событий, калькулятора
- `startTimer()` — обратный отсчет до даты `buhlo_target_date`
- `calculateAlcohol()` — расчет закупки по людям/дням/интенсивности
- `loadEvents()` — localStorage -> data/events.json fallback
- `submitRegistration(eventId)` — запись на событие
- `hasUserRegistered(eventId)` — проверка, записан ли текущий пользователь

### Админка (`pages/admin.html` + `js/admin.js`)
- пароль admin: `buhlo_admin_password`
- session key: `buhlo_admin_logged_in`
- `saveEvent()` — создать/обновить событие
- `deleteEvent()` — удалить событие
- `renderEvents()` — список событий
- `downloadEventsJson()` / `importEventsJson()` — экспорт/импорт JSON
- `changeAdminPassword()` — смена пароля
- `saveEventsToServer()` / `loadEventsFromServer()` — синхронизация через API, если `window.BUHLO_API_URL` задан

## Данные
- События хранятся в `localStorage` как массив объектов:
  - `id`
  - `title`
  - `date`
  - `time`
  - `location`
  - `description`
  - `participants[]`
  - `maxParticipants`
- Регистрация пользователя на событие хранится отдельно в `REGISTRATIONS_KEY`.

## Важные особенности
- В `main.js` и `admin.js` пароль по умолчанию жёстко зашит: `Terminator1981`.
- Это проект без backend по умолчанию; всё работает через browser storage.
- Для серверной синхронизации нужен внешний proxy, а не прямой доступ к GitHub token из браузера.
- appEvents и default events содержат два события: Пятничный сбор и Глобальный выезд на Нёман.
